# 🛍️ E-Commerce Website

A responsive e-commerce website developed as a web development project. The project focuses on creating a clean and user-friendly shopping interface with product browsing, user interaction, and essential e-commerce functionality.

## 📌 Project Overview

This project demonstrates the development of an e-commerce website using modern web development technologies. It provides users with an interactive interface for browsing products and navigating through different sections of an online shopping platform.

The project was developed to strengthen practical skills in **HTML, CSS, JavaScript, responsive web design, and frontend development**.

## ✨ Features

* 🏠 Responsive Home Page
* 🛍️ Product Browsing
* 🔎 Product Search / Navigation
* 🛒 Shopping Cart Interface
* 👤 User Registration / Login Interface
* 📦 Product Details
* 💳 Checkout Interface
* 📱 Responsive Design
* 🎨 Clean and User-Friendly UI
* 🔗 Navigation Between Multiple Pages

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and functionality
* **Git & GitHub** – Version control and project management

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/harshapasupuleti859-png/Ecommerrce-website-project.git
```

### 2. Open the project

```bash
cd Ecommerrce-website-project
```

### 3. Run the website

Open the main `index.html` file in a web browser.

For a better development experience, the project can also be opened using **VS Code with Live Server**.
